# DSH Live2D Pet - 网页感知伴侣扩展 (Edge / Chrome)

本扩展是 `dsh-girl-live2d` (v1.1.01+) 的可选轻量外设扩展，用于让桌宠感知用户的出行、租房、购物等特定场景，实现人设化的单次关心问候与上下文同步。

---

## 🌟 核心特性与行为准则

1. **单次关怀，无视彻底静默**：
   - 伴侣检测到特定场景（如携程订机票、链家租房、淘宝购物）后，仅在气泡中发起**单次轻量问候**。
   - 若用户 20 秒内不回复，伴侣**自动复位静默，绝不重复打扰或死缠烂打**。
2. **纯本地回环回路（Zero-Cloud Leak）**：
   - 数据通过浏览器直接发往本地回环 `http://127.0.0.1:19387/dsh-pet/perception/web-event`。
   - 不依赖任何第三方云端或外部中转，绝对保护隐私。
3. **独立开关，随开随关**：
   - 随时在浏览器扩展图标中一键关闭场景同步，伴侣侧也有独立开关。

---

## 🛠️ 安装方法（Edge / Chrome 通用）

1. 打开浏览器扩展管理页面：
   - **Microsoft Edge**：访问 `edge://extensions/`
   - **Google Chrome**：访问 `chrome://extensions/`
2. 开启右上角或左下角的 **「开发者模式」 (Developer mode)**。
3. 点击 **「加载已解压的扩展程序」 (Load unpacked)**。
4. 在弹出的文件选择器中，选中本目录：
   ```
   dsh-girl-live2d/desktop/browser_extension/
   ```
5. 安装完成！点击工具栏上的拼图图标固定本扩展即可查看状态。

---

## ⚙️ 配置说明

- 默认端口为 `http://127.0.0.1:19387`（DSH Web / 伴侣服务默认端口）。
- 若您使用自定义端口启动伴侣，在扩展弹窗中修改对应地址并点击「测试连通性」即可。
